# 飞书侧配置详解（阶段 5 的背景知识）

两个产品共用用户自己的飞书多维表作数据中台，但**鉴权互相独立**：

| 产品 | 鉴权方式 | 能力 |
| --- | --- | --- |
| 提示词助手（读） | lark-cli device-flow 登录的**个人身份**（user） | 只读多维表 + 下载附件 |
| 剪藏插件（写） | **企业自建应用**凭据（App ID/Secret → tenant_access_token） | 读写多维表 + 上传附件 |

## 一、多维表副本（数据中台本体）

剪藏库模板（含 9 字段：分类、工作台分类、内容、可直接复制提示词、封面、链接、标题、风格码、
使用模型）由发布者维护，用户**必须创建副本**：

- 模板直达链接（若失效则以插件设置页「01 配置指南」里的链接为准）：
  <https://zk5ckzju3h.feishu.cn/base/SCEObFKEvaNjNhsJT3bcZuoKnSe>
  （「网页剪藏库」，发布者飞书文档 <https://zk5ckzju3h.feishu.cn/docx/BIxhdJC0GoOvr3xHtDlcztIqnRd>
  的「配置说明」一节也挂了此模板链接）。
- 操作：打开模板 → 右上「...」→「创建副本」→ 复制范围选**仅结构**（不要复制数据）→
  副本存到用户自己的云空间，表名可自定义。
- 副本链接（浏览器地址栏 URL）同时给插件设置页和助手设置页用，两边粘**同一条**。
- 直接把模板母版链接填进插件会被拦截（插件内置审查：母版是只读的，剪藏数据写不进去）。

> 给用户解释时可以这样说：模板是「表格的图纸」，复制副本才是你自己的仓库；插件往副本写，
> 助手从副本读。

## 二、企业自建应用（插件写入的通行证）

1. 打开 <https://open.feishu.cn/app> → **创建企业自建应用**（个人账号也能建）。
2. 权限管理 → 开通权限，**三个都要**：
   - `bitable:app`（多维表格读写——写入记录）
   - `bitable:app:readonly`（多维表格只读——同步分类选项）
   - `drive:file:upload`（上传附件——封面图/视频）
3. **发布应用版本并上线**——未发布的应用调 API 全部失败，这是最高频的「我都配了还是报错」原因。
4. 凭证与基础信息页复制 `App ID` 和 `App Secret` → 填进插件设置页「02 连接飞书」。
   Secret 只存在本机浏览器存储，不经过任何第三方。

## 三、把应用加进副本（授权读写）

在**副本**多维表右上「...」→「添加文档应用」→ 搜索刚建的应用 → 添加并设【可编辑】。
不加这一步，插件写入会报 `91403 NOTEXIST`（详见 troubleshooting.md）。

## 四、插件设置页配置顺序

1. 任意普通网页（不能是 chrome:// 页）点扩展图标 → 浮层右上设置图标 → 进入设置页。
2. 「02 连接飞书」：App ID、App Secret。
3. 「03 收藏位置」：粘贴副本链接（自动提取 app_token）+ 数据表名（副本默认「剪藏」，可留空）。
4. 「04 分类与模型」：点「从飞书同步选项」拉取分类/模型选项（一级分类默认 生图提示词/视频提示词，
   模型写入「使用模型」单选字段，表格里需先有同名选项）。
5. 保存。

## 五、助手设置页配置

1. 托盘右键 → 设置 → 数据源。
2. 粘贴同一个副本链接 → 解析（提取 app_token）。
3. 立即同步：表名含「提示词」的表自动接入，字段映射自动识别。认不出的表手动
   「添加数据表 → 选表 → 自动识别字段」。
4. 环境自检应全绿（lark-cli ✓ / 登录 ✓ / 数据源 ✓ / 缓存目录 ✓）。

## 六、device-flow 登录的原理（阶段 3 给用户解释用）

`lark-cli auth login --no-wait` 返回一个 `verification_url` + `device_code`；用户在浏览器打开
链接、登录自己的飞书、点授权；CLI 拿 device_code 轮询换 token。要点：

- device_code **十分钟有效**，过期重新走一遍即可，不会产生脏数据。
- 授权页要求勾选的域 = `base,drive`（多维表 + 云盘附件）。
- 身份是 user（个人身份）——助手只用这个身份**读**用户自己的表，不涉及应用凭据。
- 判断成功的唯一标准：`auth status` 输出 JSON 里 `identities.user.status == "ready"`。

## 七、常见提问的官方答案

- **要花钱吗**：不花钱。个人飞书账号即可，多维表个人版容量足够。
- **数据存哪**：全在用户自己的飞书云空间（多维表副本），本地只有缓存。
- **安全吗**：App Secret 只在本机浏览器；lark-cli 登录态只存在本机 lark-cli 自己的数据目录
  （`%APPDATA%\LarkShell\` 下，由 CLI 自管）；两个产品都开源，代码可查。
- **换电脑**：重跑本 skill 即可；飞书侧（副本、应用、登录授权）不用重建，只需在新机器重新
  登录 + 粘贴链接。
