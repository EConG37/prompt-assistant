# 产品清单：提示词助手 × 网页剪藏插件

版本与下载源以 skill 根目录 `sources.json` 为准（本文件只描述装完的样子与形态，避免两处改版本号）。

## 提示词助手（Windows 托盘应用）

- **仓库**：<https://github.com/EConG37/prompt-assistant>（MIT，开源）
- **形态**：Electron 托盘应用，NSIS 安装包（`.exe`，约 80MB），仅 Windows x64。非一键式安装，
  可自选目录，默认 `%LOCALAPPDATA%\Programs\提示词助手`，无需管理员权限。
- **运行环境自足**：内置 Node 运行时（跑 lark-cli 子进程不需要系统 Node）。
- **数据存放**：全部在 `%APPDATA%\提示词助手\`（config.json 配置、cache.json 同步缓存、
  images\ 媒体缓存、app.log 日志）。卸载默认保留（`deleteAppDataOnUninstall: false`）。
- **装完的样子**：右下角托盘蓝紫气泡图标。左键开/收右侧吸附面板（搜索、两级分类、卡片点复制、
  媒体预览）；右键弹常用提示词菜单，点击即复制；屏幕右缘悬浮把手，移开 0.55s 自动收回。
- **首次配置入口**：托盘右键 → 设置 → 数据源（粘多维表链接）→ 环境自检 / 一键自动配置。
  应用内 设置 → 配置与使用 有图文说明页。

### lark-cli（助手唯一的外部依赖）

- 飞书官方 CLI，读取多维表 + 附件下载用。助手通过它免密钥复用本机已登录的飞书身份。
- **便携版**：npmmirror 官方单文件（`https://registry.npmmirror.com/-/binary/lark-cli/`），
  `lark-cli-<版本>-windows-amd64.zip` 解压出 `lark-cli.exe` 即用，免 Node/npm。
- 安装位置约定：`%APPDATA%\提示词助手\runtime\lark-cli\lark-cli.exe`（应用「一键自动配置」同路径，
  二者互不冲突；脚本与本 skill 也用这个位置）。
- 关键命令：`--version` / `auth status` / `auth login --no-wait --json --domain base,drive` /
  `auth login --device-code <码> --json`。登录身份 user，权限域必须显式 `base,drive`。

## 网页剪藏插件（浏览器扩展）

- **仓库**：<https://github.com/EConG37/feishu-web-clipper>（MIT，开源）
- **形态**：Chrome MV3 扩展，GitHub release 提供源码 zip（约 0.2MB），解压后开发者模式
  「加载已解压的扩展程序」。最低 Chrome 111（Edge 等价）。
- **装完的样子**：工具栏翡翠绿书签图标。任意网页点击 → 网页右上角浮层：第一步选封面图、编辑
  标题与提示词，第二步选分类/模型，保存进多维表。支持图片与视频（建议 30M 内）。
- **解压目录即安装目录**：扩展长期引用该文件夹，不能删不能挪；先挪到固定位置（如
  `文档\feishu-web-clipper\`）再加载。
- **设置页四分区**：01 配置指南（带 10 张截图的飞书侧配置图文）/ 02 连接飞书（凭据）/
  03 收藏位置（目标表）/ 04 分类与模型（从飞书同步选项）。
- **剪藏写入字段**：标题、内容、链接、封面、分类（多选）、使用模型（单选）——字段名必须与
  多维表完全一致，模板副本已带好。
- **模板审查**：设置页直接填模板母版链接会被拦截（母版只读）。必须先创建用户自己的副本。

## 二者的数据契约

同一个飞书多维表（用户自己的副本）。插件往里**写**（标题/提示词/标签/封面/视频/链接），
助手从中**读**。助手同步时表名含「提示词」的数据表自动接入；字段映射自动识别
（标题 / 可直接复制提示词·提示词·内容 / 子分类·分类 / 封面 / 成品视频 / 链接 / 提示词用途·作用）。

两个产品**互不依赖对方的凭据**：插件用企业自建应用凭据（App ID/Secret）写；
助手用 lark-cli 的个人登录态（user 身份）读。这就是为什么阶段 5 里应用和登录要分别配。
