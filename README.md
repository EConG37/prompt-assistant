# 提示词助手

常驻 Windows 托盘的提示词速查 / 一键复制工具。数据来自使用者自己的飞书多维表
（首次使用在 设置 → 数据源 粘贴多维表链接即可），
无需任何密钥配置——直接复用本机已登录的 `lark-cli` 身份读取多维表。

## 下载安装

Windows 安装包：[GitHub Releases](https://github.com/EConG37/prompt-assistant/releases/latest)
（下载最新的 `Setup.x.y.z.exe`，双击安装）。安装后打开 设置 → 数据源 → 环境自检 →「一键自动配置」即可完成环境准备。

## 工作流：剪藏插件（存） × 提示词助手（用）

本软件需配合**浏览器剪藏插件**使用，二者以**飞书多维表**为数据中台：

```
浏览器剪藏插件 ──写入──▶ 飞书多维表（数据中台） ──同步──▶ 提示词助手（托盘速查/复制/预览）
   负责“存”：网页上看到的        表内按字段存放：           负责“用”：右键一键复制、
   提示词/图片/视频一键收集       标题、提示词、标签、         右侧吸附面板预览、
   进多维表对应数据表             封面、视频、来源链接         高频统计、常用词管理
```

- **剪藏端**：浏览器「网页剪藏插件」（v1.7.4，安装包与图文教程见下方说明文档），
  在浏览器里把看到的提示词、参考图、视频一键剪藏进多维表（写入哪张表，本软件就同步哪张表）；
- **使用端**：本软件同步多维表后，在托盘/吸附面板里按 大类（常用词/生图词/视频词）→ 细分（人物/环境/…）浏览，点击即复制；

### 剪藏插件说明文档

<https://zk5ckzju3h.feishu.cn/docx/BIxhdJC0GoOvr3xHtDlcztIqnRd>（软件内 设置 → 配置与使用 → 「剪藏插件下载与图文教程」也可打开）

要点摘录：

1. **安装插件**：下载文档内附件 `剪藏插件-1.7.4.zip` 解压 → 浏览器扩展程序页 → 「加载已解压的扩展程序」→ 选中解压文件夹；
2. **准备多维表**：打开文档内的「网页剪藏库」模板链接 → **务必先创建副本到自己空间**（复制范围选「仅结构」，表名可自定义）；
3. **配置机器人**：飞书开放平台创建企业自建应用 → 权限管理开通 `bitable:app`、`bitable:app:readonly`、`drive:file:upload` → 发布上线 → 在自己多维表「… → 添加文档应用」中加入该应用并设为【可编辑】；
4. **标签同步**：多维表里自定义好分类/标签后，在插件设置里点同步即可拉取；
5. **媒体限制**：支持图片与视频，视频建议 30M 以内；
6. 最后把**自己那份多维表**的链接粘贴到 提示词助手 设置 → 数据源 → 解析，即可同步使用。
- **字段约定**（剪藏写入时使用这些列名，本软件可自动识别映射）：
  `标题`、`内容`（正文）、`使用模型`（适用模型）、`添加时间`（排序）、`子分类`/`分类`（标签）、`封面`（预览图）、
  `成品视频`（视频预览）、`链接`（来源）、`提示词用途`/`作用`（常用词表用法）；
- 表名含「提示词」的数据表会在同步时自动接入，无需手工配置。
- 正文直接读取「内容」，预览与复制均使用剪藏时整理好的文本；旧常用词表兼容「提示词」「正文」等普通文本列。升级时自动迁移旧的「可直接复制提示词」映射，原文为空也不会回退到 AI 计算列。请在浏览器插件剪藏时完成提示词删改。

## 快速开始

```bash
npm install          # 已安装可跳过
npm start            # 或双击「启动提示词助手.vbs」（无控制台窗口）
```

启动后：

- **右下角托盘**出现「提」字图标，常驻不退出。
- **左键托盘**：打开 / 收起右侧吸附面板（固定展开，不随鼠标收回）。
- **右键托盘**：弹出常用提示词菜单（条目少时平铺、多时按标签分组），点击即复制全文。
- **屏幕边缘引号入口**：36×76 的黑底白色引号与橙色竖线，不透明度默认 80%，可在设置中调整。鼠标移入立即展开；移出默认等待 40 ms 开始收回，可调整为 0–60 ms。面板用 160 ms 滑入淡入、120 ms 滑出淡出，鼠标移回时可中途反向。单击入口固定展开，也可在面板右上角切换固定状态；按住 Ctrl 可拖动入口。
- **双列图库**：深色图标侧栏切换全部、常用词、生图词、视频词、收藏、高频、Skill；顶部搜索及两个下拉框筛选类型和细分类，支持最新、最热、已收藏排序筛选。无图条目直接展示正文摘录，Skill 使用紧凑文字列表。
- **快速复制与收藏**：点击卡片标题或悬停后的复制按钮复制全文；右下角书签加入常用词与托盘菜单。搜索快捷键为 Ctrl+K。
- **直接添加常用提示词**：点击侧边栏顶部「新建」，填写标题和正文，点击「保存到飞书」。可选择已接入的常用提示词表，保存成功后立即显示，默认收藏并加入托盘菜单；支持 Ctrl+Enter 保存。输入期间面板保持展开，保存失败或取消时保留输入。需要飞书表格的编辑权限，未接入时可直接前往设置。旧本地条目可在表单内「一并迁移」，只在云端写入成功后移除旧记录，保留收藏和复制统计。
- **向左悬停预览**：停留在卡片约 0.32 秒，向左打开独立的小预览窗，显示适用模型、图片、可滚动全文、标签、复制、来源链接和收藏。鼠标在图库与预览之间移动时保持展开；离开两者后关闭预览，未固定的图库同时收回。Esc 先关闭预览，再收起面板。模型来自表格的「使用模型」等列，支持多个模型；没填写时显示「未标注」。
- **媒体预览**：同步使用者自行接入的数据表，图库卡片显示封面图或视频角标，标题下方可收藏。
  提示词全文、模型、标签与播放控件显示在独立预览窗中。媒体缓存位置可在「外观与行为」中调整。
  点击封面图打开**应用内独立预览窗**；视频先展示封面，点击后播放，切换条目或关闭预览会停止播放。屏幕左侧空间不足时，预览会自动调整到可见区域。
- **两级分类**：提示词标签页内第一行为大类（常用词 / 生图词 / 视频词，带数量），第二行为细分
  （生图词→人物/环境/生物/海报/创意图片；视频词→成品/创意；常用词→按标签如人物设定/场景搭建），通过侧栏及下拉框逐级筛选。

## 提示词删除与同步

提示词删除：侧栏点击「管理」进入选择模式，可勾选单条或「全选结果」后批量删除。选择范围仅限当前搜索、分类和排序筛选中的提示词，Skill 不参与删除；提示词侧面预览的删除按钮和设置页也支持单条删除。确认框会说明飞书源记录将一并删除，其他设备同步后也会移除。未迁移的旧本地条目只从本机删除。

删除优先采用飞书接口的明确成功回执，避免列表更新延迟造成误报；回执不明确的条目会自动延迟核对，核对期间不重复发送删除请求。失败或断网时保留未确认的条目，并可只重试失败项。删除成功后保存本机删除标记，拦截正在返回的旧同步结果，也覆盖重启后的旧缓存；后续一轮完整同步确认远端不存在后才清理标记。飞书删除已有记录后，下一次成功同步即移除本机条目，不再使用新增后五分钟保留规则。同步读取失败或分页不完整时保留旧缓存，不把它当作空表。同步进行期间在桌面新增的条目仍会保留，等下一轮完整读取再以飞书为准。

## 本机 Skill

在原「常用句」位置增加「Skill」入口，其他导航保持原有顺序。应用启动时自动发现当前用户下已存在的 `.agents/skills`、`.agent/skills`、`.codex/skills`、`.claude/skills`、`.zcode/skills`、`.workbuddy/skills`、`.trae/skills`、`.cursor/skills` 和 `.gemini/skills`。只扫描这些技能目录，不遍历 Agent 的聊天记录、缓存或整个磁盘。「设置 → Skill」可添加项目、自定义或插件目录，也可移除默认目录。

若旧版本已手动设置过扫描目录，升级后继续保留原列表；点击「设置 → Skill → 自动发现目录」可将新发现的 Agent 目录补入列表，同时保留手动添加的目录。Skill 页右上角的刷新只扫描当前目录列表，不触发飞书同步。

- 自动读取 `SKILL.md` 的名称和说明，支持嵌套目录、多行 YAML 说明、目录链接去重；同名但不同位置的技能分别展示。
- 鼠标悬停条目时在面板侧面显示详情，点击条目也可打开并聚焦浮窗。可直接修改中文别名、分类和用途备注，再点击「保存整理」。编辑时浮窗保持打开，未保存草稿在关闭后再次打开时恢复（仅当前应用会话）。搜索同时覆盖这些信息。
- 分类使用可搜索、新建的选择器，可选「未分类」清除分类；方向键切换候选，Enter 选择，Esc 先取消分类输入，再按一次关闭详情。设置页共用该控件，并可统一重命名或删除分类。
- 收藏沿用现有书签操作，收藏的技能出现在「已收藏」及托盘 Skill 分组；复制次数参与「高频」，不会自动改变收藏状态。
- 调用提示词包含技能名称、本机文件位置和待填写任务，可在浮窗中改写任务后复制；调用词编辑只影响本次复制，不改写技能文件。「本机已发现」表示在扫描目录中找到文件，实际能否加载由目标 Agent 的环境与权限决定。
- 扫描和复制均不执行技能脚本。部分格式不规范的技能会尽量提取说明并标注；不可读的旧记录暂时保留并提示重新扫描，文件移除后刷新会从列表中移除。
- 技能索引保存在 `%AppData%\提示词助手\skills.json`；分类、备注和扫描目录保存在 `config.json`，收藏及复制统计沿用现有本机存储。重新扫描不会覆盖这些偏好，相关数据不上传飞书。

旧「常用句」功能已移除；升级时仅将独立旧短句转为普通提示词，保留内容、ID、收藏和复制统计。来自收藏的重复入口不再生成。此改动不改变现有提示词的分类和同步方式，回退旧程序仍可读取转换后的提示词；技能索引与整理信息可留待后续版本继续使用。

## 数据是怎么来的

1. 应用通过本机 `lark-cli`（已登录你的飞书账号）调用多维表接口，分页拉取启用表的记录；
2. 按字段映射归一化为 `{标题, 正文, 模型, 添加时间, 标签, 预览图, 备注}`，缓存到
   `%AppData%\提示词助手\cache.json`，离线时仍可使用上次同步结果；
3. 「效果」等附件字段可选下载到 `%AppData%\提示词助手\images\`，在卡片右侧显示缩略图；
4. 默认同步表为「常用提示词库」（标题=提示词用途、正文=提示词、标签=作用、预览图=效果）。
   想同步其它表（如「生图提示词-人物」「视频提示词-成品提示词」）：设置 → 数据源 → 添加数据表 →
   选表 → 「自动识别字段」即可（已适配 标题/内容/使用模型/分类 等常见列名）。

> 若换机器或 lark-cli 未登录：先 `lark-cli auth login`，或在设置页把 lark-cli 路径指向可执行文件。

## 换电脑 / 打包给别人用

**环境自检**：设置 → 数据源 → 「环境自检」→「**一键自动配置**」：自动从国内镜像下载安装 lark-cli
（官方单文件程序，带 sha256 校验；**无需安装 Node/npm**，应用内置运行环境），随后自动打开飞书登录页引导授权。
也可以逐项手动处理（去登录 / 去配置）。

**换机步骤**：
1. 新电脑装本软件（无需装 Node.js，运行环境内置）；
2. 打开应用 → 设置 → 数据源 → 环境自检 →「一键自动配置」（自动装 lark-cli + 引导登录飞书）；
3. 粘贴你的多维表链接 → 解析 → 立即同步；
4. 同步时**表名含「提示词」的表会自动接入**（字段映射自动识别），无需手工配表 ID。

**打包卫生（分发前检查）**：
- 安装包内不含任何个人数据：配置/加星/复制统计/文字缓存都在 `%AppData%\提示词助手\`（不随文件夹分发），日志也写在 AppData；
- 分发前建议：设置 → 外观与行为 → 「清空缓存」（清掉安装目录 `cache\media` 里你下载过的封面/视频），并删除安装目录内残留的 `cache\` 文件夹内容；
- 代码默认值不含任何个人多维表地址/表 ID（首次使用由使用者自行粘贴链接）；
- 启动脚本（vbs/bat）使用自身所在目录的相对路径，放到任何位置都能运行。

## macOS 支持

本应用同时支持 macOS（Apple Silicon）：

- **打包**：`npx electron-builder --mac` 产出 dmg / zip；应用图标需 1024px（electron-builder 自动转 icns）
- **菜单栏**：自动加载 `assets/trayTemplate.png` 模板图标（随系统深浅色自动反色）；
  修改 logo 后运行 `node tools/gen-tray-template.js` 重新生成（白色字形转为镂空）
- **Dock**：以 `LSUIElement` 代理应用运行（只有菜单栏图标，不占 Dock）
- **lark-cli 探测**：图形应用继承的 PATH 较窄，应用会自动补搜 `/opt/homebrew/bin`、
  `~/.npm-global/bin` 等常见位置，并为子进程注入增强 PATH（`#!/usr/bin/env node` 脚本可正常启动）
- **开机自启**：走 macOS 登录项（路径不加引号）；「开机自动启动」在 mac 上显示为「登录 Mac 时自动启动」
- **首次打开**：未做开发者证书签名时，右键 .app →「打开」→ 再点「打开」

## 开发

界面字体统一使用随应用打包的阿里巴巴普惠体 2.0（Regular / Medium / SemiBold / Bold），覆盖面板、预览、设置和表单，离线加载。原版字体与版权信息位于 `assets/fonts/`，字体声明参见该目录的 `NOTICE.md`，不改变用户系统字体。运行 `node tools/check-fonts.cjs`（使用下方 Playwright 环境）可检查三个窗口实际渲染的字体及四字重离线加载；截图位于 `output/playwright/fonts/`。

```bash
node tools/gen-icon.js   # 重新生成托盘图标
node tools/gen-tray-template.js  # 生成 macOS 菜单栏模板图标（改 logo 后）
npm start                # 开发运行（--enable-logging 可看渲染进程日志）
npx electron-builder --mac      # 打 macOS dmg/zip（arm64）
```

图库回归检查：已有 `playwright-core` 时运行 `node tools/check-gallery.cjs`，或先设置 `PLAYWRIGHT_CORE_PATH` 指向其安装目录。脚本在 `output/playwright/gallery-profile` 创建隔离数据，用实际 Electron 窗口验证布局、搜索、收藏、预览与收回，输出截图；不会修改正式配置或系统剪贴板。本地存在视频缓存时会额外检查播放与停止。

开合动效检查：同样的环境下运行 `node tools/check-panel-motion.cjs`，测量开合响应，验证重复开合时卡片布局稳定、关闭中途反向、旧动画回调隔离及减少动态效果模式，报告保存在 `output/playwright/motion-report.json`。

悬浮入口默认不透明度为 80%，可在「设置 → 外观与行为 → 悬浮入口」调节至 10%–100%，实时预览并自动保存；展开的面板、预览和设置窗口始终保持不透明。设置页使用与图库统一的暖白、深灰、橙色风格，并支持深色主题。

设置回归检查：同样环境下运行 `node tools/check-settings-appearance.cjs`，验证透明度实时更新、保存与重新载入、连续修改不同选项，以及浅色/深色和最小窗口宽度布局；截图保存在 `output/playwright`。

同步预览回归检查：同样环境下运行 `node tools/check-sync-preview.cjs`，使用隔离模拟数据点击实际同步按钮，检查连续同步后悬停、同步期间悬停，以及原生预览窗口隐藏后再次悬停的恢复。

图库默认「最新」按表格中的添加时间从新到旧排列，跨表合并后统一排序；自动识别添加时间、创建时间等列，也可在数据源映射中指定时间列。升级后同步一次即可获取时间；没有有效时间的条目放在后面，同一时间保持原有顺序。分类、搜索、收藏沿用时间顺序，「最热」仍按复制次数排序。桌面端新增时会写入可编辑的时间列；表中没有时间列时，本机保留这条记录的创建时间，用于后续排序。

添加时间排序检查：同样环境下运行 `node tools/check-newest-order.cjs`，使用模拟 CLI 数据验证时间字段同步、日期格式转换、跨表排序、筛选与缓存重载。

模型与原文检查：同样环境下运行 `node tools/check-model-content.cjs`，验证旧 AI 正文映射迁移、直接读取内容、模型同步、图片/视频预览、复制与设置映射；截图保存在 `output/playwright/preview-model-*.png`。

云端新增检查：同样环境下运行 `node tools/check-cloud-prompts.cjs`，使用隔离配置与模拟飞书 CLI，验证侧栏新增、正文原样写入、重复提交保护、失败保留输入、与同步并行、旧条目迁移和收藏；不会向真实飞书表格写入测试记录。

删除检查：运行 `node --test tools/feishu-deletion.test.cjs tools/prompt-deletion.test.cjs` 检查删除回执、列表更新延迟、自动核对、跨表分批、删除标记、来源隔离和存储失败；运行 `node tools/check-prompt-deletion.cjs` 使用隔离 Electron 和模拟 CLI 验证远端删除、单条/批量删除、部分失败重试、同步并发、重启、离线和窄窗口确认，并确认删除成功后的旧列表不会使条目复活。截图位于 `output/playwright/delete/`，不操作真实飞书记录。删除标记仅在本机配置中保留，不上传或随安装包分发。

Skill 检查：运行 `node --test tools/skills.test.cjs` 验证元数据读取、嵌套目录与链接去重、分类收藏持久化、文件失效和旧短句迁移。使用上述 Playwright 环境运行 `node tools/check-skills.cjs` 验证实际 Electron 窗口中的分类、搜索、收藏、调用复制、深色窄窗口、目录管理和分类重命名/删除，截图位于 `output/playwright/skills/`。测试使用隔离目录和剪贴板。

Skill 交互约定：复用独立原生预览窗口，避免把悬浮详情裁切在窄侧栏中；分类采用原生 Popover 和可搜索列表，适配应用内置的 Electron 33。输入、分类选择和保存期间保护浮窗，失焦后可正常收回，未保存草稿仅保留在当前会话。分类、备注仍使用原存储结构，回退这次界面改动无需迁移数据。

发布隐私检查：打包后运行 `node tools/audit-release.cjs`，扫描源码与应用资源中的凭据格式、本机配置与缓存标识、Skill 整理信息、私人长正文、图片元数据和默认数据，报告保存至被忽略的 `output/privacy/release-audit.json`。使用 `--history` 额外检查所有本地分支与标签中的历史文件和提交邮箱，另存 `release-history-audit.json`。报告只记录命中位置与类型，不输出用于比对的私人值。若已将安装包内的 `resources/app.asar` 解包至 `output/privacy/<版本号>/payload/`，还会比对其与已扫描应用资源是否一致。

新建提示词直接保存在飞书多维表，断网时可查看上次缓存；旧的待迁移条目仍保存在 `%AppData%\提示词助手\config.json` 的 `local` 节点；
托盘菜单「常用」= 打了 ★ 的条目，未打星时自动取前 14 条。
