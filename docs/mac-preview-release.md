面向 Apple Silicon（M 系列芯片）的 Mac 体验版，感谢 @Anna-YC 在 PR #1 中贡献 macOS 适配。

下载 `.dmg`，打开后将「提示词助手」拖入「应用程序」；也可下载 `.zip` 解压使用。启动后应用常驻菜单栏，不显示 Dock 图标。

- 支持菜单栏深浅色图标、本机 Skill 扫描、飞书提示词新增、同步和删除。
- 首次使用在「设置 → 数据源」完成飞书环境配置与授权。
- 本体验版没有 Apple 开发者证书签名或公证。首次打开可能需要在「系统设置 → 隐私与安全性」中允许本次打开。
- 当前下载包仅适用于 M 系列芯片，暂不提供 Intel Mac 包。

本次包由 GitHub 的 Mac 环境构建，并验证打包后的面板、设置页、空白初始数据以及应用启动。同步、删除与 Skill 数据层使用隔离模拟数据验证；更多实际使用反馈欢迎提交 Issue。

Windows 用户继续使用稳定版 v2.8.1。本预发布不会替换 Windows 稳定版下载入口。
