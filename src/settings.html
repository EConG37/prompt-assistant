配置与使用说明

01
项目地址

本应用与配套浏览器剪藏插件均开源在 GitHub，更新走 Releases 发布；遇到问题可去提 Issue。

一、这套工具是怎么配合的

剪藏插件负责“存”，提示词助手负责“用”，二者以你自己的飞书多维表为数据中台，形成一条完整链路：

浏览器剪藏插件 ──存──▶ 飞书多维表（数据中台） ──同步──▶ 提示词助手（托盘/面板 取用·复制·预览）
  • 刷网页时：遇到好提示词、封面图、视频，点一下浏览器里的剪藏插件，自动写进你的多维表；
  • 用 AI 时：鼠标滑到屏幕右缘，提示词助手面板滑出，搜到即复制，全程不用打开网页。

二、配置剪藏插件与剪藏多维表（负责“存”）

1
准备剪藏多维表

打开说明文档里的「网页剪藏库」模板 → 先创建副本到自己空间（复制范围选“仅结构”）。 要给剪藏插件写入权限：飞书开放平台创建企业自建应用 → 开通 bitable:app、bitable:app:readonly、drive:file:upload 权限并发布 → 在你的多维表「… → 添加文档应用」中加入该应用并设为【可编辑】。

2
安装浏览器剪藏插件

下载插件包解压 → 浏览器「扩展程序」页 → 「加载已解压的扩展程序」→ 选中解压文件夹。 之后浏览网页遇到喜欢的提示词、封面图、视频，点一下插件即可剪藏进你的多维表。 插件包下载与图文教程见顶部「项目地址」模块。

三、安装并登录飞书 lark-cli（负责“通”）

3
下载安装 lark-cli（一键）

本工具内置运行环境，不用自己装 Node。打开左侧「数据源」→ 点「环境自检」→ 点弹窗里的「一键自动配置」，会自动下载安装 lark-cli（约 15MB，官方单文件程序，走国内镜像并做完整性校验）。

4
登录飞书

一键自动配置过程中会自动打开飞书登录页，在浏览器里授权即可； 也可随时在环境自检里点「去登录」。本工具通过本机 lark-cli 的登录态读取多维表，不需要填写任何密钥。

5
验证登录态

回到「数据源」→「环境自检」→ 点「重新检查」： 「飞书登录态」一行显示 ✓ 已登录：你的账号 即为成功； 显示「!」则点该行的「去登录」重试。同步读数据全靠这个登录态，务必确认通过。

四、接入本工具，开始同步（负责“用”）

6
粘贴链接，接入同步

复制你自己那份多维表的链接 → 左侧「数据源」粘贴 → 点「解析」→「立即同步」。

  • 表名含「提示词」的数据表会自动接入，字段映射自动识别，一般无需手工配置；
  • 想同步其它表：「添加数据表」→ 选表 →「自动识别字段」即可；
  • 同步完成后回到面板，看到卡片就说明配置成功。

五、日常怎么用

  • 打开面板：鼠标移到屏幕右缘的悬浮把手 → 面板滑出；移开约半秒后自动收回，不打扰工作。 左键托盘图标 = 固定展开 / 收起面板；
  • 快速复制：右键托盘图标 = 常用提示词菜单，点击即复制全文；
  • 浏览筛选：两级分类——大类（常用词 / 生图词 / 视频词 / 高频）→ 细分（人物 / 环境 / …），顶部可搜索；
  • 卡片操作：点卡片 = 复制提示词全文；点封面图 = 放大预览（无图卡片点 ✦ 占位图 = 预览全文，ESC 关闭）；点视频 ▶ = 内联播放；
  • ★ 设为常用：同步出现在面板常用句页与托盘右键菜单；
  • 高频统计：每次复制自动计数，「高频」分类按使用次数排序，方便复盘自己的常用库；
  • 本地条目：「提示词」「常用句」标签页可新建仅存本机的内容，不写进多维表。

六、设置页各标签速查

  • 数据源：多维表链接解析、选择同步哪些表、字段映射、自动同步间隔、立即同步、环境自检；
  • 提示词：浏览已同步内容、设为常用 / 复制、查看复制统计、新建本地提示词；
  • 常用句：本地短文本快捷复制项的增删改；
  • 外观与行为：主题与主题色、吸附边（右 / 顶）、面板宽度、预览行数、收回延时、 媒体缓存位置与无痕模式、开机自启。

七、数据都存在哪里

  • 提示词 / 图片 / 视频原文：你的飞书多维表（唯一数据源，本工具只读同步，断网时用上次缓存）；
  • 设置、加星、复制统计：本机系统应用数据目录 %AppData%\提示词助手（不随安装包分发）；
  • 预览图 / 视频缓存：默认安装目录 cache\media，可在「外观与行为」更改或一键清空； 关闭「缓存到磁盘」即无痕模式，退出自动清空。

八、遇到问题

  • 同步失败、图片裂图：数据源 →「环境自检」逐项排查，或点「一键自动配置」自动修复 （自动装 lark-cli、引导登录；lark-cli 为官方单文件程序，从国内镜像下载并做完整性校验）。 如果自动配置没反应或修复失败：点「复制给 AI 助手排查」，把生成的话发给你电脑上的 AI 编程助手（ZCode / Cursor 等），它会按你机器的实际缺失自动修好并引导登录；
  • 改了多维表字段名：到对应数据表卡片点「自动识别字段」重新映射；
  • 换电脑：装上本软件 → 环境自检 →「一键自动配置」→ 粘贴多维表链接解析， 表名含「提示词」的表会自动接入，无需手工配表。

环境自检

换电脑或首次使用时点一遍。先点「一键自动配置」自动装好 lark-cli 并引导登录； 如果它没反应或修复失败，点「复制给 AI 助手排查」，把生成的话发给你电脑上的 AI 编程助手（如 ZCode / Cursor），它会按你机器的实际缺失自动修好并引导登录。
